# Між нами — соціальна версія v1

## Що вже є
- Реєстрація та вхід через Supabase Auth.
- Профіль з унікальним `@username`, ім’ям, описом та HTTPS-посиланням на аватар.
- Пошук користувачів за ім’ям або username.
- Запити в друзі та прийняття запитів.
- Приватні спільні простори за кодом і спільні нотатки.
- Щоденні завдання та PWA для встановлення на головний екран.

## 1. Supabase
1. Відкрий Supabase → SQL Editor → New query.
2. Скопіюй увесь `supabase_schema.sql`, встав і натисни Run.
3. Відкрий Project Settings → API.
4. Скопіюй Project URL та anon/publishable key. **Не використовуй service_role key.**

## 2. config.js
Заміни в `config.js` `https://YOUR-PROJECT.supabase.co` та `YOUR_SUPABASE_ANON_PUBLIC_KEY` на значення свого проєкту.

## 3. GitHub Pages
Завантаж усі файли з архіву в корінь репозиторію, підтверди Commit changes і дочекайся оновлення Pages. На iPhone відкрий сайт у Safari → Поділитися → На початковий екран.

## 4. Перевірка
Створи акаунт на одному телефоні, підтверди пошту, створи другий акаунт на іншому пристрої, знайди його за @username, надішли запит і прийми його. Далі створи спільний простір та передай код.

## Важливі обмеження v1
Це перша робоча основа, а не завершена велика соцмережа: поки немає приватних чатів, стрічки публікацій, блокування/скарг, відновлення пароля та завантаження аватарів. Пошук профілів відкритий для авторизованих користувачів; спільні нотатки захищені RLS. Для публічного запуску варто додати rate limits, модерацію та перевірку унікальності username на рівні БД.
